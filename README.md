# Power BI Sales & Business Performance Analytics

## Project Overview

This project analyzes sales data using Microsoft Power BI.

## Task 1 - Data Import & Cleaning

The dataset was imported into Power BI and cleaned using Power Query.

### Data Cleaning Steps

- Removed duplicate records
- Checked missing values
- Cleaned text fields
- Corrected data types
- Converted date fields to Date format
- Converted numerical fields to appropriate numeric data types

## Dataset Columns

- Order ID
- Date
- Product
- Quantity
- Unit Price
- Total
- Region
- Salesperson
